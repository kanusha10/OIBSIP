# Digital Library Management System

A web-based Digital Library Management System developed as part of the Oasis Infobyte Java Development Internship.

## Features

- User registration and login
- Role-based access for users and administrators
- Book management
- Book issue and return management
- Book reservation
- Contact/query management
- Admin dashboard
- User dashboard
- MySQL database integration
- RESTful APIs using Spring Boot
- Spring Security-based authentication and authorization

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL

### Frontend
- HTML
- CSS
- JavaScript
